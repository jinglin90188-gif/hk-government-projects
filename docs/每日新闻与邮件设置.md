# 每日新闻与邮件

## 已安排的流程

- 香港时间上午8点：项目采集及网站发布，保留原流程。
- 香港时间下午2点：新闻采集、摘要及网站发布。GitHub定时任务可能延迟，2点是启动时间，并非保证送达时间。
- 网站：首页预览3条；news.html 显示完整清单及按日期归档。
- 每次最多10条，限过去48小时。没有新消息不凑数；来源读取失败与没有新闻分别显示。
- 来源：政府新闻公报、政府新闻网、香港电台、机场管理局及港铁。只有公开页面及RSS；没有登录及付费墙绕过。
- 主题：交通科技、低空与无人驾驶、的士及网约车、机场铁路、城市数字化、相关交通政策及基建。常规事故、封路、优惠等不作为重点新闻。

## AI摘要（待配置）

聊天里的GPT登录不等于后台API授权。GitHub Models已于2026年7月30日退役，不能依赖旧的免费接口。

打开仓库 Settings → Secrets and variables → Actions。

Secrets 添加：

- NEWS_AI_API_KEY：你选择的模型服务的API密钥，勿填ChatGPT账号密码。

Variables 添加：

- NEWS_AI_BASE_URL：模型服务提供的HTTPS OpenAI兼容基础地址，末尾不加 /chat/completions。
- NEWS_AI_MODEL：服务商提供的准确模型名称。

模型服务可能收费，先自行确认价格和额度再启用。未配置、正文未取得或模型调用失败时，页面显示“原文提要”，不标成AI摘要。成功生成的AI摘要会缓存，不重复调用。摘要附内部原文证据检查，但不等于人工审稿。

## Gmail每日邮件（默认关闭）

不需要给收件人的公司邮箱密码，只需给发件Gmail配置应用专用密码。应用专用密码存进GitHub Secrets，不能写进仓库文件、网页或聊天。

1. 在发件Google账号开启两步验证，再创建应用专用密码；若账号不支持，请换支持SMTP的发件邮箱。官方说明：https://support.google.com/accounts/answer/185833?hl=zh-Hans 。
2. 仓库 Settings → Secrets and variables → Actions → Secrets，添加：
   - SMTP_USER：发件Gmail地址。
   - SMTP_PASSWORD：Google应用专用密码，不是日常登录密码。
   - NEWS_MAIL_TO：你的收件公司邮箱。
3. 在 Variables 添加 SMTP_HOST，值 smtp.gmail.com；SMTP_PORT，值465。
4. 确认收件地址及设置后，在 Variables 添加 NEWS_MAIL_ENABLED，值true。未设置或不是true时绝不发送。
5. Actions 手动运行流程，选择 news（只更新新闻），检查“发送每日新闻邮件”步骤；首次配置可使用同样方式测试。

邮件在网站发布成功后发送，只发尚未发送的近48小时新闻；全源失败、无新消息、旧归档均不发送。记录SMTP接受结果不保证到达收件箱，需检查垃圾邮件。若发送后记录保存失败，不能盲目重跑，先检查邮箱以免重复。

## 故障检查

仓库 Actions → 对应运行记录；网页下方“查看本次新闻来源”展示各来源状态。模型或邮件配置失败不应伪装成功；API密钥和收发件人资料不输出到公开新闻JSON。

浏览器预览环境不可用时只做自动化功能检查，手机布局需实际打开核查。
