# OpenTender 研究与机构合并

## 已实施

主清单同时读取 projects.json 和 institutions.json，保留各自采集及历史文件。机场、港铁、港深科技园等已有来源统一搜索、按机构筛选、收藏及导出。沿用现有业务相关性规则，不新增评分。

正式招标、采购计划、RFI、EOI、资格预审分别显示；已过期采购计划默认隐藏。按机构及标准化编号去重，正式招标优先于同编号采购计划，合并来源。机构来源获取失败不影响政府主库加载；旧资料明确显示检查时间。

这不是补齐所有机构数据：来源页面仍可能只提取部分记录；遇到登录、验证码或访问限制，不绕过。

## OpenTender 调研结果

检查日期：2026-11-18。

- https://opentender.hk/about ：自述为非官方、每日更新的公开招标索引，覆盖进行中、已截止及已批出合约。可参考其发标机构目录、分类、截止日期、历史记录与官方原文链接。
- https://opentender.hk/terms ：本次检查未发现可据此批量复用其数据库的明确数据许可证，也未发现对外 API 文档。
- 搜索 opentender.hk + GitHub、域名精确匹配及 hkdevb-tender-listing-app，未找到可核实属于该网站的公开源代码仓库。这不等于证明其没有仓库。
- https://github.com/clawnify/OpenTender 为同名投标资格审查工具，README 指向 Clawnify，非香港招标数据库；不可当作该网站的源码。

继续从发标机构官方公开来源采集，以 OpenTender 作为人工查漏参考，不接入未公布的内部接口，不复制第三方整库。若日后取得其公开 API 或数据许可，再评估补充接入。
